## About Me

- Rust が好きで、サーバーフレームワークから GPU レンダリングまで Rust で書いています
- リアルタイム・ステートフルなサーバー、ボクセル、物理シミュレーションに興味があります
- インフラは Google Cloud 派です
- Web アプリは TypeScript + Next.js で作っています
